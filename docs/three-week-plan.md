# Plan de tres semanas
## Semana 1 — Planificación y desarrollo
Crear Boards, repositorio, arquitectura, ramas; completar funcionalidades iniciales y PRs trazables.
## Semana 2 — CI, calidad y seguridad
Azure Pipelines, GitHub Actions, pruebas, revisión de dependencias, secretos, self-hosted agent; conservar evidencia auténtica de una ejecución fallida, diagnóstico, corrección y ejecución exitosa.
## Semana 3 — Estabilización y release
Completar pruebas y documentación, publicar artefacto, validar ambientes/aprobaciones, etiquetar y demostrar `v1.0.0`.
El calendario es una propuesta; ajustarlo a las fechas oficiales de entrega.
