# Branching strategy
- `main`: stable and protected where the platform permits.
- `feature/<short-name>`: new capabilities.
- `fix/<short-name>`: defect corrections.
- `refactor/<short-name>`: technical-debt work.
- Link work to Azure Boards using `AB#<ID>` in branch/commit/PR descriptions where supported.
- Merge through reviewed Pull Requests; do not invent review evidence.
